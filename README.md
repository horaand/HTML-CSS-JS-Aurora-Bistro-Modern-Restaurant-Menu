# Aurora Bistro — Modern Restaurant Menu

An interactive restaurant menu built with **vanilla HTML, CSS, and JavaScript**.  
No frameworks, no external libraries, no images, no network calls — **works fully offline**.

## ✨ Features
- Modern responsive UI with **filters, search, and sorting**
- Dietary toggles: **Vegan**, **Vegetarian**, **Gluten-free**, **Spicy**
- **Add to cart** with live **Subtotal / Tax / Total**
- **LocalStorage** cart persistence
- **Print** order summary
- Accessibility: ARIA roles, live regions, keyboard-friendly
